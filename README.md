# Wedding_Invitation

Wedding invitation website for Dimal Joseph & Soniya

## Tech Stack
- React + Vite
- Tailwind CSS
- Google Apps Script (backend)
- Google Sheets (database)

## Features
- Beautiful Christian wedding theme
- RSVP flow with family count
- Live countdown timer
- Admin dashboard
- Google Sheets integration

## Setup
1. `npm install`
2. `npm run dev`
3. `npm run build` for production

## Google Sheets Setup
- Create a Google Sheet with "RSVPs" tab
- Add headers: Timestamp, Guest Name, Attending, Family Count, Submitted At
- Deploy Apps Script as Web App
